# Word Guessing Game

## Description
This is a simple command-line Python game where the player has to guess a secret word within a limited number of attempts. After each wrong guess, the game shows how many guesses are left. If the player guesses correctly, they win; otherwise, the game ends when all attempts are used.

## Features
- Uses while loops to allow multiple guesses
- Uses if-else conditions to check the guess
- Shows remaining guesses after each wrong attempt
- Handles user input with .strip() to ignore extra spaces

## How to Play
1. Run the Python script
2. Enter a word as your guess
3. Keep guessing until you find the secret word or run out of attempts
4. The game will notify if you won or lost

## Learning Outcomes
- Practice with loops, conditionals, and user input
- Understand simple game logic and state management
- Learn how to provide feedback to users
